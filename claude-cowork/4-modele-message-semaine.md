# Le message de chaque semaine

Le message se prépare dans l'application, pas à la main.

1. Onglet **Semaine**, sur la semaine à prévoir (flèche › pour la semaine suivante).
2. **🤖 Choisir les menus avec Claude** : mettez à jour le congélateur, le frigo (⚠️ devant ce qui doit
   être mangé vite), les fruits et légumes, le placard et vos envies. Le stock est gardé d'une semaine à l'autre
   et partagé entre les deux téléphones.
3. **📋 Copier le message pour Claude**, puis collez-le dans une nouvelle conversation du projet
   « Menus de la semaine ».
4. Une fois les menus validés avec Claude, saisissez-les dans l'app avec **Choisir…** sur chaque repas.

Le message contient automatiquement :
- les repas à prévoir à partir d'aujourd'hui : jour, postes, activités, heure, qui mange, temps de cuisine,
  étiquettes (Express, Prêt à l'avance, En plusieurs temps, Jour de cuisine, VTT, Grands-parents) ;
- les plats déjà verrouillés dans l'app et les repas marqués « Pas de repas à prévoir » ;
- le stock et les envies saisis ;
- les notes des repas des deux dernières semaines (À refaire, Bof, Martin a aimé).
